# 游戏日历生成器

## 项目概述
这个脚本用于从游研社网站获取游戏发售数据并生成 ICS 日历文件，让用户可以在日历应用中查看游戏发售信息。

## 功能特点
- 爬取游研社的游戏发售数据，获取游戏发售信息（虽然代码里写的是获取两年的数据，但是一般能拿到的也就几个月的，很多游戏不会过早的公布发售日期）
- 生成标准 ICS 格式日历文件
- 日历事件包含游戏名称、发售日期、平台、标签、简介和价格等信息

## 使用方法
### 1. 直接使用
```bash
https://raw.githubusercontent.com/xiyiji-official/GameIcs/refs/heads/main/my.ics
```
使用本项目的生成的ics文件链接作为**订阅链接**导入到你的日历应用中（如 Google Calendar、Outlook 等）

*以下内容为AI生成，不保证正确，仅供参考。*
#### 一、苹果日历（适用于 iPhone、iPad 和 Mac）
#### （一）iPhone 和 iPad
打开 “日历” 应用。
轻点屏幕底部的 “日历” 按钮。
轻点左下角的 “添加日历”。
选择 “添加订阅日历”。
在提供的字段中粘贴您获取到的 ics 订阅地址（通常以.ics 结尾）。
轻点 “订阅”，之后您可以按需调整日历的名称、颜色等设置。
轻点 “添加” 以完成订阅。此时，您订阅的日历中的事件将会自动同步显示在您的苹果日历中。
#### （二）Mac
打开 “日历” 应用。
在屏幕顶部的菜单栏中，点击 “文件”。
选择 “新建日历订阅…”。
在弹出的窗口中，粘贴 ics 订阅地址。
点击 “订阅”。
按需调整设置，然后点击 “好” 以完成订阅。之后，该日历的事件就会显示在您的 Mac 日历中。
#### 二、Google 日历
打开 Google 日历网站（calendar.google.com）并登录您的账号。
在页面左侧，找到 “其他日历” 部分，点击该部分右侧的向下箭头。
选择 “导入日历”。
在弹出的窗口中，将 ics 订阅链接粘贴到 “日历网址” 框中。
点击 “添加日历” 按钮，完成订阅。订阅后，您可以在 Google 日历中查看并管理新添加的日历，该日历中的事件将自动更新。
#### 三、Outlook 日历
#### （一）Outlook 网页版
登录 Outlook 网页版（outlook.live.com/calendar/0/）。
在导航窗格中，选择 “添加日历”。
选择 “从 web 订阅”。
将 ics 订阅链接粘贴到输入框中。
点击 “导入”，您还可以在 “日历名称” 中输入您想要的日历名称，方便识别。
再次点击 “导入” 完成操作。之后，该日历的事件就会同步显示在您的 Outlook 网页版日历中。
#### （二）Outlook 桌面应用
打开 Outlook 桌面应用。
点击 “文件” 选项卡。
选择 “打开 & 导出”>“导入 / 导出”。
在 “导入和导出向导” 框中，选择 “导入 iCalendar (.ics) 或 vCalendar 文件 (.vcs)”，然后选择 “下一步”。
在弹出的文件选择窗口中，找到并选择您的 ics 文件（如果您是通过链接订阅，可先将链接在浏览器中打开，下载对应的 ics 文件）。
选择 “确定”，项目将自动导入到日历中。
#### 四、安卓手机系统日历（以常见的华为、小米手机为例，不同品牌和系统版本可能略有差异）
#### （一）华为手机
打开 “日历” 应用。
点击日历界面右上角的三个点，选择 “设置”。
在设置页面中，找到 “账户”>“添加账户”>“其他日历”。
选择 “添加通过网址导入”。
粘贴 ics 订阅链接，然后按照提示完成后续操作，如为该日历命名等。完成后，您订阅的日历事件将显示在华为手机日历中。
#### （二）小米手机
打开 “日历” 应用。
点击日历界面右上角的 “+” 号，选择 “订阅日历”。
在弹出的页面中，粘贴 ics 订阅链接。
点击 “确定”，等待日历数据加载完成，即可在小米手机日历中查看订阅日历的事件。

## 2. 本地运行
### 1. 安装依赖
```bash
pip install -r requirements.txt
```
1. 运行脚本：
```bash
python main.py
```
2. 脚本会自动爬取游戏数据并生成 `my.ics` 文件
3. 将生成的 ICS 文件导入到你的日历应用中（如 Google Calendar、Outlook 等）
